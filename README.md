# kav-sw19/homebrew-tap

Homebrew formulae for [whosup](https://github.com/kav-sw19/whosup), a live terminal view of your
coding-agent sessions (pi, Claude Code, Codex, opencode, Gemini CLI, aider), their sub-agents and
open terminals.

```sh
brew install kav-sw19/tap/whosup
```

The formula is updated by whosup's release workflow.
